# Portfolio

Personal site of Axel Bluhme: a short bio followed by a gallery of selected work.

Plain HTML, CSS and JS with no build step.

- `index.html`: the bio and gallery. To add an image, put it in `images/` and add a `<a class="tile">` line with its `width` and `height`.
- `style.css`: the layout and theme.
- `main.js`: arranges the masonry columns in order and runs the lightbox (arrow keys, Esc, swipe).

Preview locally:

    python3 -m http.server 4173
